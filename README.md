## Penerangan Aplikasi

Aplikasi ini mengandungi tiga bahagian utama:

1. **Profil** — memaparkan tajuk, pengenalan diri (nama, bidang pengajian, hobi),
   gambar profil, dan carta bar tahap kemahiran.
2. **Kalkulator BMI** — pengguna memasukkan berat dan tinggi, aplikasi mengira
   BMI serta memaparkan kategori berat badan.
3. **Kalkulator Umur** — pengguna memilih tarikh lahir, aplikasi mengira umur.

Susun atur menggunakan **sidebar** (menu navigasi + pemilih mood) dan
**kolum (columns)** untuk paparan yang kemas.

## Cara Menjalankan

 Jalankan aplikasi:
   ```bash
   streamlit run app.py
   ```

 Aplikasi akan terbuka secara automatik di pelayar web pada alamat
   `http://localhost:8501`.
